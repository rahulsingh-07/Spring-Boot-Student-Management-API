🎓 Student Management REST API (Spring Boot)
A simple and clean implementation of:

✅ Spring Boot
🔄 MapStruct for DTO ↔ Entity mapping
📦 spring-boot-starter-validation (Jakarta Validation)
🧾 Custom Exception Handling using @RestControllerAdvice
📑 Use of DTO, Entity, ResponseDTO, and Mapper pattern

📌 Overview
This project demonstrates how to build a robust REST API with:
Full CRUD operations for managing students
Request data validation using annotations
MapStruct to simplify DTO ↔ Entity mapping
Exception handling with custom messages
Separation of concerns (Controller → Service → Repository layers)
